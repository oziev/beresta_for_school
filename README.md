# Береста

Веб-сервис для учителей: комплекты раздаточных материалов, привязанные к этапам урока по ФГОС, с педагогическими фишками и адаптивным режимом ученика.

Стек: **FastAPI · SQLAlchemy async · PostgreSQL 15 · Redis 7 · GigaChat · WeasyPrint · python-docx · Jinja2 + Alpine.js + HTMX + Tailwind**.

## Быстрый старт

```bash
git clone <repo>
cd beresta

cp .env.example .env
# Заполните GIGACHAT_CLIENT_ID / GIGACHAT_CLIENT_SECRET
# или поставьте BERESTA_LLM_STUB=true для офлайн-демо

docker compose up -d --build
curl http://localhost:8000/ping     # → {"status":"ok"}
```

Открыть в браузере: **http://localhost:8000**.

### Без ключей GigaChat (stub-режим)

```dotenv
BERESTA_LLM_STUB=true
```

## Ключевые API (на доработке)

- `GET /lesson-types` — каталог типов уроков с этапами по ФГОС.
- `POST /upload-lesson-plan` — парсинг файла плана (TXT/PDF/DOCX).
- `POST /generate-from-plan` — основная генерация комплекта.
- `POST /generate-from-scratch` — экспресс-генерация без плана.
- `GET/POST/PUT/DELETE /kits` и `/kit-items` — CRUD комплектов.
- `POST /kits/{id}/variants` — три разноуровневых копии (US-06).
- `POST /kits/{id}/fork` — форк на основе оценок урока (US-10).
- `POST /kits/{id}/ungeneratable` — рукописный (негенерабельный) элемент.
- `POST /kits/{id}/hot-mistakes` — «Горячая десятка» ошибок (US-12).
- `POST /kit-items/{id}/generate-example` — пример с ошибками (US-16).
- `PUT /kits/{id}/reorder` — drag-and-drop порядка раздаток.
- `POST /export/kit/{id}/{pdf|docx|zip}` — экспорт (PDF с layout 4-карточки/флипчарт/A3, DOCX с таблицами, ZIP с папками по этапам).
- `GET/PUT /design-settings` — оформление (шрифт, поля, служебные поля).
- `GET/POST/DELETE /sources` — библиотека источников.
- `GET/POST /profile`, `POST /profile/train`, `POST /profile/reset` — виртуальный двойник учителя.
- `GET /reflection/{id}` — методическая рефлексия (промпт №4).

## Основные фишки (ДОРАБОТКА)

### 1. РЕЖИМЫ СОЗДАНИЯ
- По плану урока — загрузка TXT/PDF/DOCX, ИИ парсит этапы
- С нуля (экстренная помощь) — ИИ сам предлагает типовой план по ФГОС
- Из шаблона — использование сохранённых комплектов

### 2. ТИПЫ УРОКОВ (ФГОС)
- Открытие нового знания
- Рефлексия
- Контроль знаний
- Комбинированный

### 3. ТИПЫ РАЗДАТОЧНЫХ МАТЕРИАЛОВ
- Карточки с заданиями
- Рабочий лист
- Памятка-опора
- Схема с пропусками
- Таблица для заполнения
- Бланк рефлексии
- Карточка с ДЗ

### 4. НАСТРОЙКИ ПЕРЕД ГЕНЕРАЦИЕЙ
- Чекбоксы этапов (только нужные)
- Слайдеры времени на этап (алгоритм отрезает лишнее)
- Глобальный слайдер сложности (легко/средне/сложно)
- Кнопки «Для слабых», «Для сильных» одним кликом

### 5. ПЕДАГОГИЧЕСКИЕ ФИШКИ
- Библиотека источников (свои или ИИ)
- Горячая десятка (типичные ошибки + лайфхаки)
- Шкала времени (тайминг на раздатке)
- Скаффолдинг (пошаговые подсказки)
- Эмоциональный интеллект (нестандартная рефлексия)
- Негенерабельный режим (рукописный элемент)

### 6. РАЗНОУРОВНЕВОСТЬ
- 3 уровня сложности (basic/medium/advanced)
- Кнопка «3 варианта» — слабые/средние/сильные за 1 клик
- Цветовая маркировка (зелёные/жёлтые/красные карточки)

### 7. ВЕРСИИ КОМПЛЕКТА
- Учительская (с ответами и критериями)
- Ученическая (чистые листы)

### 8. ЭКСПОРТ
- PDF (4 карточки на лист, 2 карточки, флипчарт)
- DOCX (редактируемый для Word)
- ZIP (папки по этапам + README)
- Титульный лист, служебные поля, нумерация

### 9. АДАПТИВНЫЙ РЕЖИМ УЧЕНИКА
- QR-код
- Диагностика (3 вопроса)
- Динамическая сложность (ошибся → легче, решил → сложнее)
- Подсказки при ошибках
- Таймер
- Финальный совет

### 10. ДАШБОРД
- Распределение по уровням
- Совет ИИ-методиста
- PDF для родителей

### 11. ВИРТУАЛЬНЫЙ ДВОЙНИК
- Сбор правок учителя
- Обучение стилю
- Автоприменение при генерации

### 12. ФОРК
- Оценка заданий (1–5)
- Комментарии («задание 3 никто не понял»)
- Автоматическая правка → новая версия

### 13. ПРИМЕР ЗАПОЛНЕНИЯ
- Типичные ошибки серым цветом
- Ученики ищут и исправляют

### 14. ИНТЕРФЕЙС
- Хлебные крошки (путь по страницам)
- Тёмная тема (для вечерней подготовки)
- Drag-and-drop загрузка файлов
- Inline-редактирование
